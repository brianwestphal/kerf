# `kerfjs/no-generated-view-edits`

Disallow hand edits to generated Kerf UI view modules (`*.view.ts`, `*.view.js`, `*.view.d.ts`).

A Kerf UI view document (`*.kui.json`) is the source of truth for a screen's composition. `kerf-ui-view generate` turns it into a read-only module that your application imports. You put state, handlers, slots, and wiring in **your own** files; editing the generated module would be lost on the next regeneration and would hide the contract changes the TypeScript compiler is meant to report.

The generator records a digest of the module body in its header. This rule recomputes it, so it needs no access to the document:

- **`edited`**: the body no longer matches the header's body digest, or the
  recorded `kui-contract` line no longer matches the contract digest.
- **`header`**: the `kui-view` / `kui-contract` header lines are damaged.
- **`missing`**: a `*.view.ts` sits beside a `.kui.json` document but is not a generated module.

Line-ending conversion (CRLF checkouts) is ignored. A `*.view.ts` with no document beside it is not checked, so unrelated files that happen to use the suffix stay unaffected.

## ❌ Incorrect

```ts
// inbox.view.ts — GENERATED by kerf-ui-view from inbox.kui.json — do not edit.
// …
export function renderInbox(inputs: InboxInputs, slots: InboxSlots): SafeHtml {
  return Pane({ background: myOverride /* ← reported: hand edit */ });
}
```

## ✅ Correct

```ts
// inbox.ts — application-owned
import { renderInbox, wireInbox } from './inbox.view.js';

mount(root, () =>
  renderInbox({ title: 'Inbox', items: items.value }, { detail }),
);
wireInbox(root, { compose: openComposer, 'open-item': ({ key }) => select(key) });
```

To change the layout, edit `inbox.kui.json` (in the editor or by hand) and run `kerf-ui-view generate`. To make a value configurable, promote the prop to a document param; the generated module then exposes it as an input.

Generated modules are formatted by the generator, so add `**/*.view.ts` (and `.view.js` / `.view.d.ts`) to `.prettierignore` as well.

See [`docs/26-ui-editor.md`](../../../docs/26-ui-editor.md) in the kerf repository.
