# Decisions on Kerf authoring defaults

KF-E5JEN9 closes the design questions in KF-QDJM2T. The evidence supports one runtime correction, changes to the default examples, and two opt-in authoring tools. Keep both proposed ownership APIs at the experiment stage. A reliable program should let its reader locate the source, the DOM it owns, and the point at which that ownership ends.

## What an author should write

| Surface                                 | Decision and migration                                                                                                                                                                                                                                                                                                                                                                                                                      | What guards the contract                                                                                                                                                                                                                        |
| --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Native global JSX and tagged-HTML holes | **Correct runtime behavior.** A mount that switches from one signal to another now retargets its text and attribute subscriptions even when both serialize identically. Consumers can remove forced rerenders that existed solely to refresh those sources. Existing public types and rendered HTML stay compatible.                                                                                                                        | Equal-markup A→B→A tests, unchanged-slot reuse, disposal and production bundle checks. Representative core grows about 0.20 KiB.                                                                                                                |
| Frequently updated scalar expressions   | **Change the default example.** Give a shared projection one stable owner: `const label = computed(() => format(count.value))`, then `<span title={label}>{label}</span>`. Infrequently changing structure still belongs in the render. Decline the inline `derived(callback)` export.                                                                                                                                                      | Scalar benchmarks, multiple owners, error recovery, disposal, escaped JSX and no-build SSR.                                                                                                                                                     |
| Editable keyed rows                     | **Change the default example.** Import `each` and `selector` from `kerfjs`. Create `const selected = selector(selectedId)` once per list owner. Give each row a stable DOM key and bind its class through a computed that reads `selected(row.id).value`. Use `bindList` from `kerfjs/list` for explicit element ownership or virtualization. Keep its existing key, content-replacement and disposer contracts.                            | Refetch with new objects, reorder an active editor, dispose, update one row and recover after a thrown render. The new per-key content/position prototype remains benchmark-only.                                                               |
| Interactive component setup             | **Retain the current public Combobox and delegated helper.** Install `wireComboboxes` once on the owning root, route its typed commit, and dispose before removing that root. For an uncontrolled field capture its seed outside the render. Changing today's `value` after blur can overwrite edits. The tested owner recipe gives each registration an `initialValue` and one callback. A simple prop alias cannot provide that lifetime. | SSR escaping, focused and blurred edits, native reset, ID reuse, IME, keyboard, pointer and repeated disposal. The scoped recipe stays opt-in. Region owners must not combine it with the manual installation. KF-Z9RA3T tracks this collision. |
| Command names, lint and inspection      | **Keep the typed action-table recipe and adopt additive tools.** Infer command names from the handler table. Enable `kerfjs/prefer-signal-leaf` when type-aware suggestions are desired. Inspect a use with `kerf-ui-doctor --explain-use file:line:column`. Keep dynamic mode and lifetime uncertainty visible in its output.                                                                                                              | Packed consumer rejects a misspelled action. Real editor edits preserve rendered values. ESLint 9 and 10, JSX alias resolution, known/unknown prop modes and real keyboard interaction are covered.                                             |

No migration requires a compiler, new JSX transform or public deprecation. Native mounts, no-build HTML, server-side string rendering and caller-owned widget teardown retain their supported paths. Every adopted change above has an implementation or recipe in the source tree.

Patch-subpath compatibility and caller-owned rows are important exceptions to a universal list recommendation. A virtual row leaving the window is disposed. ## Can authors infer correctness?

Eight independent model sessions attempted four tasks each, with two sessions per guidance condition. Strict compilation and all four working browser behaviors on the first attempt were achieved by 0/2 Kerf current, 0/2 Kerf candidate, 2/2 Solid/Kobalte and 1/2 React/React Aria. All four Kerf answers put `each` under `kerfjs/list`. The supplied card listed both entry points without saying which exported which function. The React failure passed browser behavior and failed typechecking. All eight sessions passed by the third attempt, after six generated repairs in total.

In a separate evaluator intervention, correcting **only the import** in each untouched Kerf answer yielded complete passes for 2/2 candidate-card answers and 0/2 current-card answers. Both current answers cast picker contracts. This supports testing the precise ownership guidance on its own. It does not establish framework-wide superiority or the effectiveness of the shipped Doctor command. The candidate was a frozen example, the model had no interactive documentation access, and one answer changes a condition's rate by 50 percentage points. KF-TDAZMB records the formative human observations separately. Executable, counterbalanced human evidence remains unavailable. [Authoring methods, first-pass scores and repair results](../../ui/ai-regressions/authoring-defaults/findings.md)

**Next evidence threshold.** KF-V2NCC6 owns an import-qualified card and an independently compilable picker retest using actual Doctor output. KF-Z9RA3T owns conflicting Combobox installations. Reconsider a public component owner or row-content option when a specific consumer needs its lifetime and demonstrates improved correctness against today's recipe. Neither prototype warrants a breaking change from this sample.
