Kerf 5.0.0, @kerfjs/ui 5.0.0. Public imports kerfjs, kerfjs/list, kerfjs/array-signal, kerfjs/actions, @kerfjs/ui/combobox and @kerfjs/ui/wire-comboboxes. JSX produces SafeHtml. mount(element, render) runs render in an effect and returns a disposer. A signal interpolated directly in an intrinsic text or attribute hole is wired to the live node. Reading signal.value in render subscribes the surrounding render. Create computed(() => scalar) for a derived value. data-key identifies a DOM row; each(items, rowFn, cacheKey?) also memoizes by item identity. selector(selectedId) gives a per-key boolean signal. delegate(root,event,selector,handler) wires events. JSX function onClick props on intrinsic elements are unsupported.
